# Support

## Questions

Open an issue with the `question` label.

## Bugs

Use the bug report issue template and include:

- Django version
- Python version
- Package version
- Relevant `DEPLOY_PROBES` settings with secrets removed
- Endpoint response and status code

## Security Issues

Do not open a public issue for vulnerabilities. Follow `SECURITY.md`.

## Supported Versions

The current `0.5.x` release line supports Python 3.10 through 3.14 and Django 5.2 LTS
and 6.0. The `0.3.x` release line remains installable for older Django projects but no
longer receives security fixes.
